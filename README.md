# HopestonePay 💰

HopestonePay is a digital payment platform similar to M-Pesa or PayPal.

## 💡 Features
- Send and receive money
- Automatic savings on every transaction
- Earn rewards/points
- Withdraw savings after reaching KSh 5000

## 💸 How it works
Example:
- Transaction: KSh 20
- System takes: KSh 17
- Saved for user: KSh 3

Savings accumulate until withdrawal threshold is reached.

## 🚀 Goal
To help users build savings effortlessly while making everyday payments.
